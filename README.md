# カワラボ カレンダー（KAWAII LAB. 推し活スケジュール）

KAWAII LAB.（CUTIE STREET / FRUITS ZIPPER / CANDY TUNE / SWEET STEADY / MORE STAR /
KAWAII LAB. MATES / KAWAII LAB. SOUTH / fav me）の予定を、**カレンダーで「いつ・誰が・どこで・何のライブ」**が
ひと目で分かるようにまとめた、推し活のための個人ツールです。

- 📅 月カレンダー／📋 リスト／🎫 チケット・締切／🛍 物販 の4つの見方
- ⚡ **同じ日にライブがかぶっている日**を自動でハイライト（行く現場を選びやすい）
- ⭐ **推し設定**：推しグループ・メンバーを選ぶと、カレンダーで目立たせ＆誕生日も優先表示
- 🚗 各イベントから **会場の地図・行き方（ドライブ）・カレンダーに追加(.ics)・メモ** が使える
- 🔄 **1時間ごとに自動で最新化**（公式サイト＋Eventernoteから取得）

---

## 使い方（かんたん）

### ① 開く
**「カワラボスケジュールを開く.command」をダブルクリック**
→ 最新の予定を取り直してから、ブラウザでカレンダーが開きます。
（初回は「ターミナルがデスクトップのファイルにアクセス」の確認が出たら「OK」を押してください）

### ② 自動更新をON（最初に1回だけ）
**「インストール_自動更新.command」をダブルクリック**
→ これで、アプリを開いていなくても1時間ごとに裏で最新情報を取りに行きます。
（止めたいときは「アンインストール_自動更新.command」）

> どちらの .command も、初回は「開発元を確認できません」と出ることがあります。
> その場合は **右クリック →「開く」** を選ぶと実行できます。

| ビュー | 内容 |
|---|---|
| 📅 カレンダー | 月ごとのカレンダー。色＝グループ。⚡＝ライブがかぶっている日。本日は枠で強調。日付タップで詳細 |

## データの出どころ

- **KAWAII LAB. 公式スケジュール**：`https://kawaiilab.asobisystem.com/live_information/schedule/list`
  （日付・会場・時間・チケット/先行/締切・出演グループ）
- **Eventernote**：各グループの先々のツアー・フェスを補完（公式にまだ載っていない遠征も拾える）

同じイベントが両方に出るときは**自動でまとめ、出演グループを合算**します。

## 正確性のしくみ（自動の見張り）

自動更新は便利な反面、「取れているつもりで実は失敗していた」と気づけないのが怖いところ。
そこで**2段構えの見張り**を入れています。

### ① 毎回の自己チェック（自動・追加費用なし）
更新のたびに、取れた中身がおかしくないかを自分で点検します。
- 件数が前回から急減した／会場・日付が空の予定が多い／取得に失敗した—などを検知。
- 結果を `data/schedule.json` の `meta`（`health` = `good` / `warn` / `fail`、`warnings`、`stats`）に記録。
- 致命的な異常（一覧0件・詳細が全滅・件数激減）のときは**新データを書かずに前回の正常データを保持**します。
- 画面側は、`warn`/`fail` のときだけ**上部に注意バナー**を出します（正常時は何も出ません）。

### ② 週1の点検（公式の生ページと突き合わせ）
`updater/spot_check.py` が、直近の公式予定をいくつか選んで**公式ページを取り直し**、
保存データと「日付・会場・タイトル・出演グループ」がズレていないか機械的に照合します。

```
python3 updater/spot_check.py        # 既定8件。結果は logs/spot_check_YYYY-MM-DD.txt / .json
```

- 「✓ ズレなし」か「⚠ 要確認」を一覧で出力。**最終判断はAI/人が公式ページを見て**行います。
- 例：`Toi Toi Toi` や `log you` は同じ事務所でも **PEAK SPOT など別プロジェクト**のグループ。
  合同イベントで名前が出ても、KAWAII LAB. だけを載せるこのアプリでは**非掲載が正しい**動きです。
  （照合対象は `data/groups.json` にある KAWAII LAB. のグループだけ）

> 週1点検の**自動実行**は、動かし方（launchd / Claude Code 定期実行）を決めてから設定します。

## 注意

- **非公式のファン用ツール**です。チケットの最終確認は必ず公式サイト・各チケットサイトで。
- **出演グループ**は自動抽出のため、フェス・対バンなどでは一部のグループしか表示されないことがあります。
  「誰が出るか」の最終確認は各イベントの公式情報でお願いします（カードの「詳細ページ」リンクから飛べます）。
- メンバーや所属グループは変わることがあります。`data/groups.json` を直せば反映されます。
- 取得元サイトの作りが変わると取得できなくなる場合があります。そのときは `updater/update_schedule.py` の
  解析部分（一覧・詳細・Eventernoteの解析関数）を直してください。`logs/update.log` に状況が残ります。
